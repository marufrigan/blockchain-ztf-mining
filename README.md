# GeoZK-Miner

Privacy-preserving blockchain framework for region-verified conflict-mineral provenance and
reacquisition governance, using Circom/Groth16 zero-knowledge proofs and Ethereum smart contracts.

The implementation, tests, evaluation scripts and measured results are in [`geozk-miner/`](geozk-miner/).
See [`geozk-miner/README.md`](geozk-miner/README.md) for setup and reproduction steps.
